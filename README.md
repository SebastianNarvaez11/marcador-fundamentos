# Marcador

App de fútbol amateur (equipos, jugadores, partidos, marcador en vivo y tabla de goleadores) que se construye a lo largo de los módulos de fundamentos de la guía **Aprende KMP**.

```text
marcador-fundamentos/
├── kotlin/   consola (módulo torneo) y app Android (módulo app)
└── swift/    Swift Package (Torneo) y app iOS (MarcadorApp)
```

Hay un tag de git por lección con el estado al terminarla: `f01-kotlin-primer-proyecto`, `f02-…`. Los tags publicados no se reescriben.

Código en español (dominio) y comentarios en español.
